# skills

Personal agent skills, each justified by where it came from and crediting what it drew on.

## Language

**Origin**:
The reason a skill exists: an incident (something that went wrong or keeps repeating) or an inspiration (a practice seen elsewhere, plus the job it should do here).
_Avoid_: motivation, background

**Source**:
Another author's skill or document a skill draws on, pinned to the commit that was read.
_Avoid_: upstream, reference, inspiration (when meaning the artifact)

**Credit**:
The metadata in a skill that names one Source: its author, project, Relation, license and pinned link.
_Avoid_: attribution, acknowledgement

**Relation**:
How a skill uses a Source: `adapted` when it reuses the Source's wording, `inspired-by` when it takes only ideas.
_Avoid_: based on, derived from
